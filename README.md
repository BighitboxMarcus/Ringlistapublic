# Ringlistapublic
Ringlista för när jag ska ringa samtal. Fungerande funktion som kan användas på telefon där jag kan lägga in alla samtal som måste göras med en anteckning om vilka personerna är. Efter samtalet kan jag tala in med diktering för att anteckna vad som sades under samtalet. Kan användas medans jag kör bil.
