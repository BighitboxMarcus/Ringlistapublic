Ringlista

Koppla listan

Görs en gång. Koden låter appen läsa och spara i din privata lista på GitHub, och sparas bara i den här telefonen.

  1. Öppna GitHub och skapa en ny kod.
  2. Namn: Ringlista. Giltighet: No expiration (eller ett år).
  3. Repository access: Only select repositories → välj Ringlista.
  4. Permissions → Repository → Contents: Read and write.
  5. Tryck Generate token, kopiera koden och klistra in här.
